# Instacart Data Analysis with Python

## Descripción del proyecto

Este proyecto forma parte del bootcamp de Ciencia de Datos de TripleTen.

El objetivo fue analizar datos de pedidos de Instacart para identificar patrones de compra y comportamiento de usuarios.

Durante el proyecto se realizaron tareas de:

- Limpieza de datos
- Tratamiento de valores ausentes
- Eliminación de duplicados
- Exploración de datos
- Análisis de comportamiento de compra
- Combinación de múltiples datasets

---

## Tecnologías utilizadas

- Python
- Pandas
- Jupyter Notebook

---

## Habilidades demostradas

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Pandas
- Data Merging
- GroupBy Operations
- Data Visualization Preparation
- Analytical Thinking

---

## Resultados

Se identificaron patrones importantes de comportamiento de compra utilizando datos reales de pedidos.

Además, se aplicaron técnicas fundamentales de limpieza y análisis exploratorio de datos utilizando pandas.

---

## Conclusiones

El análisis permitió detectar horarios y días con mayor actividad de pedidos, así como los productos más comprados por los usuarios.

También se reforzó la importancia de limpiar y preparar correctamente los datos antes de realizar análisis exploratorios.
