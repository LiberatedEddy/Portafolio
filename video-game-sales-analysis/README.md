# Video Game Sales Analysis

## Descripción del proyecto

Este proyecto forma parte del bootcamp de Ciencia de Datos de TripleTen.

El objetivo fue analizar datos históricos de ventas de videojuegos para identificar patrones que permitan detectar proyectos exitosos y apoyar estrategias de marketing.

Durante el análisis se trabajó con:

- limpieza de datos
- análisis exploratorio
- visualización de datos
- análisis de plataformas
- análisis regional
- pruebas estadísticas

## Objetivos del análisis

- Identificar plataformas populares
- Analizar tendencias de ventas
- Comparar géneros y regiones
- Detectar factores de éxito
- Validar hipótesis estadísticas

---

## Resultados

Se identificaron patrones importantes en ventas de videojuegos según plataforma, género y región.

Además, se realizaron pruebas estadísticas para comparar calificaciones y comportamiento de usuarios.

---

## Conclusiones

El análisis permitió detectar diferencias importantes entre mercados regionales y plataformas de videojuegos.

También se comprobó la utilidad del análisis exploratorio y las pruebas estadísticas para apoyar decisiones de negocio.
