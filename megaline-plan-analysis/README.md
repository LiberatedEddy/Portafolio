# Análisis de Clientes de Telecomunicaciones

## Objetivo
Analizar datos de clientes de una empresa de telecomunicaciones con el fin
de comprender patrones de uso, ingresos y posibles factores relacionados
con el abandono del servicio.

## Dataset
El proyecto utiliza múltiples conjuntos de datos relacionados con:
- Usuarios
- Tarifas
- Llamadas
- Mensajes
- Consumo de internet
- Ingresos mensuales

## Herramientas
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn

## Metodología
1. Carga y exploración de datos
2. Limpieza y corrección de tipos
3. Enriquecimiento de variables
4. Análisis de consumo y facturación
5. Interpretación de resultados

## Resultados
- Existen diferencias claras de consumo entre tarifas.
- El uso de internet es el principal componente del ingreso mensual.
- Algunos patrones de uso podrían asociarse con mayor riesgo de abandono.

## Conclusiones
Este análisis permite entender el comportamiento del cliente y puede ser
utilizado para mejorar estrategias de retención y segmentación.
