# User Data Cleaning and Analysis with Python

## Descripción del proyecto

Este proyecto forma parte del bootcamp de Ciencia de Datos de TripleTen.

El objetivo fue limpiar, transformar y analizar información de usuarios utilizando Python.

Durante el proyecto se desarrollaron procesos de:

- Limpieza de datos
- Transformación de strings
- Conversión de tipos de datos
- Automatización mediante funciones
- Filtrado de información
- Análisis básico de usuarios

---

## Tecnologías utilizadas

- Python
- Jupyter Notebook

---

## Habilidades demostradas

- Data Cleaning
- Data Transformation
- Python Programming
- List Handling
- Conditional Logic
- Function Development
- Basic Data Analysis

---

## Resultados

Se logró automatizar la limpieza y análisis básico de datos de usuarios utilizando funciones y estructuras de control en Python.

Además, se implementaron filtros para segmentar usuarios según edad, categorías favoritas y nivel de gasto.
