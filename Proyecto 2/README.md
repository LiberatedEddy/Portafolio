Descripción:
En este proyecto realice un análisis exploratorio y estadístico de un conjunto de datos de videojuegos con el objetivo de identificar patrones en ventas, calificaciones de usuarios y diferencias entre plataformas, géneros y regiones.

Herramientas utilizadas:

Python

Pandas y NumPy

Matplotlib y Seaborn

SciPy (pruebas de hipótesis)

Contenido del análisis:

Limpieza y preparación de datos

Análisis exploratorio de variables clave

Comparación de calificaciones entre plataformas

Pruebas de hipótesis para validar diferencias estadísticas

Interpretación de resultados

Conclusiones principales:

Existen diferencias significativas en las calificaciones de usuarios entre distintas plataformas.

El género del videojuego influye en la percepción del usuario.

Se observan variaciones regionales relevantes en el comportamiento del mercado.
