# Music Streaming Analysis with Python

## Descripción del proyecto

Este proyecto forma parte del bootcamp de Ciencia de Datos de TripleTen.

El objetivo fue analizar el comportamiento de usuarios de una plataforma de streaming musical utilizando Python y pandas.

Durante el proyecto se realizaron procesos de:

- Limpieza de datos
- Tratamiento de valores ausentes
- Eliminación de duplicados
- Estandarización de categorías
- Análisis exploratorio de datos
- Comparación de comportamiento entre ciudades

---

## Tecnologías utilizadas

- Python
- Pandas
- Jupyter Notebook

---

## Habilidades demostradas

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Pandas
- Data Transformation
- GroupBy Operations
- Data Filtering
- Analytical Thinking

---

## Resultados

Se identificaron diferencias en los hábitos de escucha musical entre distintas ciudades y días de la semana.

Además, se aplicaron técnicas fundamentales de limpieza y análisis exploratorio de datos utilizando pandas.

---

## Conclusiones

Los resultados muestran que los hábitos de escucha cambian dependiendo de la ciudad y del día de la semana.

También se comprobó la importancia de limpiar correctamente los datos antes de realizar análisis, especialmente al trabajar con valores ausentes y categorías inconsistentes.
