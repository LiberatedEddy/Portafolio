# Limpieza y Transformación de Datos con Python
## Descripción del proyecto

Este proyecto forma parte del bootcamp de Ciencia de Datos de TripleTen.

El objetivo fue practicar conceptos fundamentales de Python aplicados a limpieza y transformación de datos.

Durante el proyecto se trabajó con:

- Manipulación de strings
- Conversión de tipos de datos
- Manejo de errores
- Uso de listas y listas anidadas
- Ordenamiento de datos
- Automatización de procesos de limpieza
## Tecnologías utilizadas

- Python
- Jupyter Notebook
## Habilidades demostradas

- Limpieza de datos
- Programación en Python
- Estructuras de datos
- Automatización básica
- Buenas prácticas de código
## Resultados

Se logró limpiar y transformar información de usuarios aplicando buenas prácticas de programación y automatización básica en Python.
